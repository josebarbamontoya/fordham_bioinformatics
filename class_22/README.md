# Class 22

* ## Genome mapping and variant calling

## Instructions to download the genome mapping and variant calling tutorial using BWA, SAMtools, Picard, and BCFtools to your home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_22/genome_mapping_and_variant_calling.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_22/genome_mapping_and_variant_calling.sh -OutFile genome_mapping_and_variant_calling.sh`
