# Class 15 outline

* ## - Getting data from public databases/repositories

## Instructions to download the NCBI data retrieval tutorial to the home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_15/retrieve_data_from_ncbi_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_15/retrieve_data_from_ncbi_tutorial.sh -OutFile retrieve_data_from_ncbi_tutorial.sh`
