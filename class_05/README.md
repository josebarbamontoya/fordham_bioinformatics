* ## Introduction to UNIX and UNIX-like operating systems and the terminal
* ## Basic UNIX commands
  
## Instructions to download the basic UNIX commands tutorial and exercise to the home directory:
1.- Open the termial
  
2.- Enter the command `cd ~`

3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_06/basic_unix_commands_tutorial.sh`

3b.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_06/basic_unix_commands_exercise.sh`

> If `wget` is not available, use `curl -O` instead

4a.- Windows users, enter the command (all in one line): `Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_06/basic_unix_commands_tutorial.sh -OutFile data_manipulation_tutorial.sh`

4b.- Windows users, enter the command (all in one line): `Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_06/basic_unix_commands_exercise.sh -OutFile github_version_control_tutorial.sh`
