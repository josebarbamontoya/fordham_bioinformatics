# Class 16 outline

* ## Processing NGS reads: QC, trimming, and filtering

## Instructions to download the QC and processing of NGS reads with fastp tutorial to your home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_16/qc_ngs_reads_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_15/qc_ngs_reads_tutorial.sh -OutFile qc_ngs_reads_tutorial.sh`
