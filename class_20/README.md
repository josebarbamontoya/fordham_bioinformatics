# Class 20 outline

* ## Structural annotation of genome and transcriptome

## Instructions to download the structural annotation of genome and transcriptomes tutorial using AUGUSTUS to your home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_20/augustus_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_20/augustus_tutorial.sh -OutFile augustus_tutorial.sh`
