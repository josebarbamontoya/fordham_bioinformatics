## Instructions to download the shell pipelines and scripting tutorials to the home directory:
1.- Open the termial
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_07/shell_pipelines_tutorial.sh`

3b.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_07/scripting_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

4a.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_07/shell_pipelines_tutorial.sh -OutFile shell_pipelines_tutorial.sh`

4b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_07/scripting_tutorial.sh -OutFile scripting_tutorial.sh`
