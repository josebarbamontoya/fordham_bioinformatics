# Class 26

* ## Machine learning in bioinformatics

## Instructions to download the SNPs PCA analysis tutorial using scikit-learn to your home directory:
1.- Open the terminal

2.- Enter the command `cd ~`

3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_26/snp_pca_analysis_scikit-learn.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line): Invoke-WebRequest `https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_26/snp_pca_analysis_scikit-learn.sh -OutFile snp_pca_analysis_scikit-learn.sh`
