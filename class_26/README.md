# Class 26

* ## Machine learning in bioinformatics

## Instructions to download the SNPs PCA analysis example using scikit-learn to your home directory:
1.- Open the terminal

2.- Enter the command `cd ~`

3a.- Mac or Unix/Unix-like system users, enter these commands (each one in one line):

`wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_26/snp_pca_analysis_scikit-learn.sh`

`wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_26/snp_pca_analysis.zip`

> If `wget` is not available, use `curl -O` instead of `wget` in each command

3b.- Windows users, enter these commands (each one in one line):

`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_26/snp_pca_analysis_scikit-learn.sh -OutFile snp_pca_analysis_scikit-learn.sh`

`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_26/snp_pca_analysis.zip -OutFile snp_pca_analysis.zip`

4a.- Mac or Unix/Unix-like system users, unzip the directory: `unzip snp_pca_analysis.zip`

4b.- Windows users, unzip the directory: `Expand-Archive snp_pca_analysis.zip -DestinationPath .`
