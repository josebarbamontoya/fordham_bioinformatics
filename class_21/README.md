# Class 21

* ## Functional annotation of genomes and transcriptomes

## Instructions to download the functional genome annotation tutorial using DIAMOND and BUSCO to your home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_21/diamond_and_busco_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_21/diamond_and_busco_tutorial.sh -OutFile diamond_and_busco_tutorial.sh`
