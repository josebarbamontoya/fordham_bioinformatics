# Class 17 outline

* ## Sequence alignment

## Instructions to download the MAFFT multiple sequence alignment tutorial to your home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_17/mafft_msa_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_17/mafft_msa_tutorial.sh-OutFile mafft_msa_tutorial.sh`
