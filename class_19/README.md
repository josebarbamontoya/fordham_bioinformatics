# Class 19 outline

* ## Genome and transcriptome assembly

## Instructions to download the genome and transcriptome assembly tutorial using ABySS/Trans-ABySS to your home directory:
1.- Open the terminal
  
2.- Enter the command `cd ~`
  
3a.- Mac or Unix/Unix-like system users, enter the command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_19/abyss_and_transabyss_tutorial.sh`

> If `wget` is not available, use `curl -O` instead

3b.- Windows users, enter the command (all in one line):
`Invoke-WebRequest https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_19/abyss_and_transabyss_tutorial.sh -OutFile abyss_and_transabyss_tutorial.sh`
