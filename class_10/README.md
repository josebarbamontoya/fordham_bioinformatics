# Class 10 outline

* ## Introduction to Python for data processing and analysis

## Instructions to download the Python tutorials to the home directory:
1.- Open the Mac or Unix-like OS terminal
  
2.- Type `cd ~`
  
3.- Enter the following command (all in one line): `wget https://raw.githubusercontent.com/josebarbamontoya/fordham_bioinformatics/main/class_10/intro_to_python_for_data_analysis_tutorial.sh`

> If `wget` is not available, use `curl -0` instead

Windows users can manually download the tutorial from the repository
